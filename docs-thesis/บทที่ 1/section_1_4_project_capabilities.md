# 1.4 ขีดความสามารถของโครงงาน

โครงงานนี้พัฒนาขึ้นโดยแบ่งระบบการทำงานตามสิทธิการใช้งานออกเป็น 3 บทบาทหลัก ดังนี้

## ผู้ดูแลระบบ

- จัดการบัญชีผู้ใช้งาน
- จัดการโครงสร้างรายวิชาและหมวดหมู่เนื้อหา
- สร้างประกาศส่วนกลาง
- จัดการสิทธิ์การเข้าถึง
- ตรวจสอบประวัติการใช้งาน (System Logs)
- ลบเนื้อหาที่ไม่เหมาะสมได้ทั้งระบบ

## ผู้สอน

- อัปโหลดไฟล์เอกสารประกอบการสอนเข้าสู่ระบบรายวิชาของตนเอง
- ดาวน์โหลดเนื้อหา
- ตรวจสอบและลบเนื้อหาที่ไม่เหมาะสมเฉพาะในรายวิชาที่ตนสอน
- ร่วมแสดงความคิดเห็นหรือตั้งกระทู้ในพื้นที่คอมมูนิตี้

## นักศึกษา

- ดาวน์โหลดสื่อการเรียนและค้นหาข้อมูลขั้นสูง
- ตั้งค่าการมองเห็นเนื้อหาที่ตนอัปโหลด
- มีส่วนร่วมในระบบคอมมูนิตี้ เช่น ตั้งกระทู้ แบ่งปันความรู้ และอัปโหลดสรุป
- สะสมคะแนน (Earn Points) จากการทำกิจกรรมเพื่อนำไปปลดล็อก (Burn Points) ฟีเจอร์ AI ระดับสูง
- ใช้งานระบบผู้ช่วยอัจฉริยะ (KMITL RAG AI)
- สร้างแผนที่การเรียนรู้ (AI Roadmap)
- แปลงเอกสารเป็นเกมการ์ดทบทวนความรู้ (AI Quiz)
