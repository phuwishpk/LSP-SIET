# 2.1 กล่าวนำ

บทนี้รวบรวมแนวคิดและหลักการที่ใช้เป็นกรอบทางทฤษฎีในการพัฒนาแพลตฟอร์มสนับสนุนการเรียนรู้สำหรับคณะครุศาสตร์อุตสาหกรรมและเทคโนโลยี สจล. โดยครอบคลุมการจัดการความรู้และการเข้าถึงสารสนเทศ การกำกับตนเองในการเรียนรู้ การเรียนรู้แบบร่วมมือ ทฤษฎีแรงจูงใจและเกมมิฟิเคชัน ตลอดจนเทคโนโลยีปัญญาประดิษฐ์ การออกแบบประสบการณ์ผู้ใช้ ฐานข้อมูล สถาปัตยกรรมซอฟต์แวร์ และความมั่นคงปลอดภัยของระบบ

กรอบแนวคิดเหล่านี้เชื่อมโยงกับปัญหาที่ระบุในบทที่ 1 ได้แก่ ข้อมูลประกอบการเรียนกระจัดกระจาย ผู้เรียนขาดแนวทางจัดลำดับการเรียน การแลกเปลี่ยนความรู้ระหว่างผู้เรียนยังไม่เป็นระบบ และการเข้าถึงเครื่องมือสนับสนุนการเรียนมีข้อจำกัด ในบทนี้จึงอธิบายหลักการแต่ละด้านควบคู่กับหน้าที่ของระบบที่นำไปประยุกต์ใช้จริง เช่น คลังความรู้และระบบค้นคืนเอกสาร KMITL RAG AI, AI Roadmap, ระบบชุมชนและการสะสมแต้ม รวมถึงการควบคุมสิทธิ์และการแยกข้อมูลในระบบหลายบริการ เนื้อหาบทนี้เป็นฐานสำหรับการอธิบายรายละเอียดการออกแบบและพัฒนาในบทที่ 3
