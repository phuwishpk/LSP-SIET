บทนี้กล่าวถึงกระบวนการออกแบบ การสร้าง และการทำงานของแพลตฟอร์มสนับสนุนการเรียนรู้สำหรับหลักสูตรของคณะครุศาสตร์อุตสาหกรรมและเทคโนโลยี สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง โดยมีเนื้อหาครอบคลุมการดำเนินงาน เริ่มจากการออกแบบสถาปัตยกรรมและฐานข้อมูลส่วนกลาง รวมถึงแผนภาพการไหลของข้อมูล แผนภาพยูสเคส และบทบาทสิทธิ์การเข้าถึง ซึ่งอธิบายภาพรวมโครงสร้างและการเชื่อมโยงการทำงาน ถัดมาคือการออกแบบและพัฒนาระบบคอมมูนิตี้ ซึ่งครอบคลุมกระบวนการตั้งกระทู้ แบ่งปันความรู้ อัปโหลดสรุปความรู้ ตลอดจนกลไกเกมมิฟิเคชัน การให้และใช้แต้มสะสม จากนั้นนำเสนอระบบปัญญาประดิษฐ์ทั้งสามส่วน ได้แก่ KMITL RAG AI ซึ่งครอบคลุมการนำเข้าเอกสาร การสืบค้น และการสร้างคำตอบพร้อมแหล่งอ้างอิง AI Roadmap สำหรับจัดทำและขยายแผนการเรียนรู้ และ AI Quiz สำหรับสร้างแบบทดสอบเพื่อทบทวนความรู้ ส่วนสุดท้ายอธิบายสถาปัตยกรรมระบบและการสื่อสารผ่าน API ระหว่างส่วนติดต่อผู้ใช้ บริการประมวลผล และฐานข้อมูล
