# เครื่องมือและแบบฟอร์มประเมินโครงงาน

เอกสารนี้เป็นร่างเครื่องมือประกอบ [แผนการประเมินโครงงาน](./evaluation_plan.md) ต้องให้ที่ปรึกษาและผู้ทรงคุณวุฒิตรวจและอนุมัติก่อนนำไปใช้เก็บข้อมูล

## 1. แบบบันทึกการทดสอบภารกิจ

### ข้อมูลผู้เข้าร่วม

- รหัสผู้เข้าร่วม: __________
- บทบาท: ☐ นักศึกษา ☐ ผู้สอน ☐ อื่น ๆ __________
- วันที่ทดสอบ: __________
- ยินยอมเข้าร่วมและบันทึกข้อมูล: ☐ ยินยอม ☐ ไม่ยินยอม

### ตารางบันทึกผลภารกิจ

| รหัสภารกิจ | เป้าหมาย/ข้อมูลที่ต้องค้น | สำเร็จหรือไม่ | จำนวนคำใบ้ | จำนวนข้อผิดพลาด/ทางตัน | หมายเหตุ |
|---|---|---|---:|---:|---|
| T1 | ค้นเอกสารที่กำหนดในรายวิชาที่ระบุ |  |  |  |  |
| T2 | ใช้คำค้นหาหรือตัวกรองหาเอกสารเป้าหมาย |  |  |  |  |
| T3 | ถาม RAG และตรวจว่าแหล่งอ้างอิงรองรับคำตอบ |  |  |  |  |
| T4 | เปิดหรือสร้างแผนการเรียนตามเป้าหมายที่กำหนด |  |  |  |  |
| T5 | ค้นหา/สร้าง/แบ่งปันเนื้อหาในคอมมูนิตี้ |  |  |  |  |
| SEC1 | ผู้ทดสอบใช้บัญชีทดสอบพยายามเปิดทรัพยากรที่ไม่มีสิทธิ์ | ต้องถูกปฏิเสธ | — |  |  |

**กติกาการให้ผลสำเร็จ:** ให้ทำเครื่องหมาย “สำเร็จ” เมื่อผู้เข้าร่วมถึงเป้าหมายตามเฉลยที่กำหนดไว้ล่วงหน้าโดยไม่ถูกผู้สังเกตบอกคำตอบ หากต้องให้คำใบ้เพื่อทำต่อ ให้บันทึกตามจริงและนับเป็นไม่สำเร็จสำหรับตัวชี้วัดแบบไม่พึ่งผู้ช่วย แต่สามารถรายงานผล “สำเร็จเมื่อได้รับคำใบ้” แยกต่างหาก กรณี SEC1 เป็นการทดสอบระบบ ไม่รวมใน Task Success Rate ของผู้ใช้

ใช้ [ชุดภารกิจและเฉลยอ้างอิง (Gold Standard)](./gold_standard_tasks.md) กำหนดคำถาม RAG เกณฑ์ตรวจคำตอบ และแบบฟอร์มเฉลยเอกสารรายวิชาให้เสร็จก่อนเริ่มเก็บข้อมูล

## 2. แบบสอบถามหลังทดลองใช้งาน

**คำชี้แจง:** โปรดเลือกคะแนนตามประสบการณ์ที่เกิดขึ้นจริงหลังทดลองทำภารกิจ  
1 = ไม่เห็นด้วยอย่างยิ่ง, 2 = ไม่เห็นด้วย, 3 = ไม่แน่ใจ, 4 = เห็นด้วย, 5 = เห็นด้วยอย่างยิ่ง  
หากไม่ได้ทดลองฟังก์ชันที่ถาม ให้เลือก “ไม่ได้ใช้งาน/ประเมินไม่ได้” และไม่นำคำตอบนั้นไปรวมในค่าเฉลี่ย

### ก. การเข้าถึงข้อมูลอย่างเป็นระบบ

| รหัส | ข้อคำถาม | คะแนน 1–5 / ไม่ได้ใช้ |
|---|---|---|
| A1 | ฉันค้นหาเอกสารหรือองค์ความรู้ของรายวิชาที่ต้องการได้ |  |
| A2 | หมวดหมู่ คำค้นหา หรือตัวกรองช่วยให้แยกข้อมูลที่เกี่ยวข้องออกจากข้อมูลอื่นได้ |  |
| A3 | ฉันทราบว่าข้อมูลหรือคำตอบที่พบมาจากเอกสารหรือแหล่งใด |  |
| A4 | หมวดหมู่และการจัดกลุ่มข้อมูลช่วยให้ฉันทราบว่าควรค้นจากส่วนใดของระบบ |  |

### ข. ความสะดวกในการใช้งาน

| รหัส | ข้อคำถาม | คะแนน 1–5 / ไม่ได้ใช้ |
|---|---|---|
| B1 | เมนูและขั้นตอนการค้นหาหรือเปิดเอกสารเข้าใจได้ง่าย |  |
| B2 | ฉันทำภารกิจที่ได้รับมอบหมายได้โดยไม่ต้องขอความช่วยเหลือมาก |  |
| B3 | การใช้แพลตฟอร์มช่วยลดความจำเป็นในการสลับไปมาระหว่างหลายช่องทาง |  |
| B4 | ฉันทำตามขั้นตอนต่อเนื่องได้โดยไม่สับสนว่าควรทำอะไรต่อ |  |
| B5 | ข้อความแจ้งสถานะหรือข้อผิดพลาดช่วยให้ฉันรู้ว่าควรทำอะไรต่อ |  |

### ค. ความตรงตามความต้องการและประโยชน์ที่รับรู้

| รหัส | ข้อคำถาม | คะแนน 1–5 / ไม่ได้ใช้ |
|---|---|---|
| C1 | ข้อมูลและเอกสารในระบบเกี่ยวข้องกับสิ่งที่ฉันต้องใช้ในการเรียน |  |
| C2 | ฟังก์ชันของระบบรองรับงานเรียนที่ฉันต้องทำ |  |
| C3 | คำตอบจาก KMITL RAG AI ตรงกับคำถามที่ฉันถาม |  |
| C4 | รายละเอียดในคำตอบจาก KMITL RAG AI เพียงพอต่อการนำไปใช้กับเรื่องที่ฉันถาม |  |
| C5 | แผนการเรียนที่ได้สอดคล้องกับเป้าหมายการเรียนของฉัน |  |
| C6 | แบบทดสอบที่ได้สอดคล้องกับเนื้อหาที่ฉันต้องเรียนหรือทบทวน |  |
| C7 | โดยรวม แพลตฟอร์มช่วยให้ฉันเข้าถึงองค์ความรู้ได้เป็นระบบ สะดวก และตรงกับความต้องการ |  |

3. หากปรับปรุงได้หนึ่งเรื่อง ท่านต้องการให้ปรับปรุงเรื่องใด

### จ. SUS

ใช้แบบสอบถาม SUS มาตรฐาน 10 ข้อฉบับภาษาไทยที่ผ่านการตรวจสอบ หากไม่มีฉบับที่เหมาะกับบริบท ให้แปลและตรวจสอบความหมายโดยผู้เชี่ยวชาญก่อนทดลองใช้ โดยแนบฉบับที่เลือกใช้และอ้างอิงแหล่งแปล/ตรวจสอบไว้ในภาคผนวก ไม่แก้ถ้อยคำหรือสูตรคะแนนเองโดยไม่ตรวจสอบผลกระทบ

## 3. แบบตรวจคุณภาพคำตอบและผลลัพธ์ AI สำหรับผู้ทรงคุณวุฒิ

|---|---:|---:|---:|---:|---|
| Q1 |  |  |  |  |  |
| Q2 |  |  |  |  |  |
| Q3 |  |  |  |  |  |
| Q4 |  |  |  |  |  |

สำหรับ AI Roadmap ให้เพิ่มการประเมินความสมเหตุสมผลของลำดับหัวข้อ ความสอดคล้องกับเป้าหมาย/ระดับผู้เรียน และความครอบคลุมของหัวข้อ สำหรับ AI Quiz ให้ประเมินความถูกต้องของคำตอบ ตัวเลือก ภาษา และความสอดคล้องกับเอกสารต้นทาง แยกคะแนนแต่ละด้าน ไม่รวมเป็นคะแนนเดียวโดยไม่ระบุวิธี

## 4. แบบประเมินความสอดคล้องของเครื่องมือ (IOC)

### วิธีให้คะแนน

- `+1` = ข้อคำถาม/ภารกิจสอดคล้องกับวัตถุประสงค์และมิติที่กำหนด
- `0` = ไม่แน่ใจหรือข้อมูลไม่พอที่จะตัดสิน
- `−1` = ข้อคำถาม/ภารกิจไม่สอดคล้อง

```text
IOC = ผลรวมคะแนนผู้ทรงคุณวุฒิของข้อนั้น ÷ จำนวนผู้ทรงคุณวุฒิ
```

### ตารางตรวจข้อคำถาม

| รหัสข้อ | วัตถุประสงค์/มิติที่วัด | ผู้ทรงคุณวุฒิ 1 | ผู้ทรงคุณวุฒิ 2 | ผู้ทรงคุณวุฒิ 3 | ผู้ทรงคุณวุฒิ 4 | ผู้ทรงคุณวุฒิ 5 | IOC | ความชัดเจน/ข้อเสนอแนะ |
|---|---|---:|---:|---:|---:|---:|---:|---|
| A1 | การเข้าถึงอย่างเป็นระบบ |  |  |  |  |  |  |  |
| A2 | การค้นและการกรองข้อมูล |  |  |  |  |  |  |  |
| A3 | การตรวจสอบแหล่งข้อมูล |  |  |  |  |  |  |  |
| B1 | ความสะดวกในการใช้งาน |  |  |  |  |  |  |  |
| B2 | การทำภารกิจโดยไม่พึ่งผู้ช่วย |  |  |  |  |  |  |  |
| C1 | ความตรงตามความต้องการ |  |  |  |  |  |  |  |
| C2 | ประโยชน์ที่รับรู้ |  |  |  |  |  |  |  |
| C5 | ความสอดคล้องของแผนการเรียน |  |  |  |  |  |  |  |
| C6 | ความสอดคล้องของแบบทดสอบ |  |  |  |  |  |  |  |

**การตัดสิน:** ใช้เกณฑ์ร่าง IOC ≥ 0.50 หากต่ำกว่าให้แก้ไขหรือตัดข้อ พร้อมเก็บข้อเสนอแนะและเวอร์ชันที่แก้ไขไว้ให้ตรวจสอบ ห้ามเปลี่ยนคำถามหลังผู้ทรงคุณวุฒิให้คะแนนโดยไม่บันทึก

## 5. แบบสรุปผลสำหรับรายงาน

| มิติ | ตัวชี้วัด | ผลที่ได้ | เกณฑ์ผ่านที่อนุมัติ | ผ่าน/ไม่ผ่าน | หลักฐาน/คำอธิบาย |
|---|---|---:|---:|---|---|
| เป็นระบบ | Task Success Rate / Search Success Rate |  |  |  |  |
| สะดวก | ความสำเร็จโดยไม่พึ่งคำใบ้ / จำนวนข้อผิดพลาด / SUS / คะแนนความง่าย |  |  |  |  |
| ตรงความต้องการ | ค่าเฉลี่ยและร้อยละระดับ 4–5 |  |  |  |  |
| RAG | ความถูกต้อง / ข้อความไร้หลักฐาน / การอ้างอิง |  |  |  |  |
| AI Roadmap/Quiz | คะแนนผู้ทรงคุณวุฒิ / สัดส่วนผลลัพธ์ที่ใช้ได้ |  |  |  |  |

รายงานจำนวนผู้เข้าร่วม วิธีคัดเลือก ช่วงเก็บข้อมูล จำนวนคำตอบที่ใช้คำนวณ ค่าเฉลี่ย/มัธยฐานของคะแนนและจำนวนข้อผิดพลาด ตลอดจนข้อจำกัด เพื่อให้ผู้ทรงคุณวุฒิตรวจสอบย้อนกลับได้
