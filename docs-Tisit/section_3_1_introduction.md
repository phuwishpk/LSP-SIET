# 3.1 กล่าวนำ

บทนี้นำเสนอการวิเคราะห์และออกแบบระบบ KMITL AI Workspace และ SIET Space โดยจัดเนื้อหาใหม่เป็น 4 ส่วนตามขอบเขตการทำงานหลักของแพลตฟอร์ม ได้แก่ การออกแบบสถาปัตยกรรมและฐานข้อมูลส่วนกลาง ระบบคอมมูนิตี้และกลไกเกมมิฟิเคชันแต้มสะสม และระบบผู้ช่วยอัจฉริยะ KMITL RAG AI การนำเสนอเริ่มจากภาพรวมการไหลของข้อมูลและสิทธิ์การเข้าถึง จากนั้นจึงอธิบายกระบวนการแลกเปลี่ยนความรู้ การให้และใช้แต้ม ตลอดจนการนำเอกสารมาค้นคืนและสังเคราะห์คำตอบด้วยปัญญาประดิษฐ์

การออกแบบสถาปัตยกรรมพิจารณาความสัมพันธ์ระหว่างส่วนติดต่อผู้ใช้ บริการ API และบริการจัดเก็บข้อมูลที่ทำงานร่วมกันผ่าน Docker Compose โดยแยกความรับผิดชอบของระบบย่อยตามหน้าที่ พร้อมใช้ MariaDB สำหรับข้อมูลเชิงสัมพันธ์และธุรกรรม และ SurrealDB สำหรับข้อมูลสมุดความรู้ แหล่งเอกสาร เวกเตอร์ และเซสชันผลลัพธ์ AI การเลือกใช้ฐานข้อมูลต่างรูปแบบตามลักษณะข้อมูลสอดคล้องกับแนวคิด Polyglot Persistence ส่วนการกำหนดสิทธิ์ประยุกต์ใช้ Role-Based Access Control (RBAC) ร่วมกับการตรวจสอบความเป็นเจ้าของและขอบเขตของห้องเรียนหรือคลังเอกสาร

ระบบคอมมูนิตี้สนับสนุนการตั้งกระทู้ การแลกเปลี่ยนเรียนรู้ การแสดงความคิดเห็น การให้ปฏิกิริยา และการแบ่งปันเอกสารสรุป กลไกแต้มสะสมเชื่อมการมีส่วนร่วมเข้ากับการเข้าถึงบริการ AI ผ่านวงจร Earn-and-Burn Loop โดยบันทึกการเปลี่ยนแปลงแต้มเป็นธุรกรรมที่ตรวจสอบได้ การออกแบบดังกล่าวมุ่งส่งเสริมการแบ่งปันองค์ความรู้โดยควบคุมกิจกรรมซ้ำและการสะสมแต้มที่ผิดปกติ

ระบบ KMITL RAG AI รับเอกสารจากคลังความรู้ แปลงข้อความเป็นชิ้นข้อมูลและเวกเตอร์ แล้วค้นคืนเนื้อหาที่เกี่ยวข้องกับคำถามด้วยความคล้ายคลึงเชิงโคไซน์ (Cosine Similarity) ก่อนส่งบริบทให้แบบจำลองภาษาสังเคราะห์คำตอบ ระบบจำกัดขอบเขตการค้นตามสิทธิ์ผู้ใช้ ควบคุมขนาดบริบท และแสดงแหล่งอ้างอิงเพื่อให้สามารถตรวจสอบที่มาของคำตอบได้ ส่วนประสบการณ์ใช้งานของทั้งสามส่วนยึดผู้ใช้เป็นศูนย์กลาง (User-Centered Design: UCD) โดยพิจารณาความแตกต่างของบทบาท ความชัดเจนของข้อมูลย้อนกลับ และความต่อเนื่องของการใช้งานระหว่างบริการ

หัวข้อ 3.2 อธิบายสถาปัตยกรรม การไหลของข้อมูล บทบาทผู้ใช้ และโครงสร้างฐานข้อมูลส่วนกลาง หัวข้อ 3.3 กล่าวถึงกระบวนการคอมมูนิตี้ การพัฒนาระบบ และกลไกแต้มสะสม ส่วนหัวข้อ 3.4 อธิบายไปป์ไลน์ AI การบริหารบริบทและโควตา ตลอดจนลำดับการทำงานของ KMITL RAG AI
